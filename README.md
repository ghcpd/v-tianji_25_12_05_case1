# Frontend Performance Test Application

A Next.js application with frontend components and performance monitoring capabilities.

## Features

- Frontend implementation with data generation
- Real-time performance monitoring
- Component render time tracking
- Computation and event handler performance logging
- Configurable performance thresholds
- Performance analytics dashboard

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Performance Monitoring

The application includes a built-in performance monitor that tracks:
- Component render times
- Computation latency
- Event handler performance
- Data fetching operations
- Operations exceeding threshold
- Slowest operations
- Percentile metrics (P50, P95, P99)
- Component-specific render statistics
